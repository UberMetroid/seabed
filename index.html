Wayland-Native Desktop Icons Built to Pair with Kelp, Reef & Shoal

Seabed renders your ~/Desktop files, folders, launchers, live image & thumbnail previews, Personal Home, Trash (trash:///), and mounted drives directly inside Main.layoutManager._backgroundGroup—with native drag-and-drop to desktop grid slots, folders, and open File Manager windows, zero fake Meta.Window hacks, and zero GTK3 subprocesses.

Engineered for Kelp, Reef, Shoal & Modern GNOME

Derived from Desktop Icons NG (DING) and stripped of external GTK3 subprocesses and X11 window-title emulation hacks.

Native Compositor Background Layer

Attaches directly to Main.layoutManager._backgroundGroup—so Kelp never tries to tile a fake desktop window and Reef never dodges your desktop wallpaper.

Drag-and-Drop & File Browser Drops

Drag icons to any grid slot on the wallpaper, drop files onto desktop folders, Home, Drives, or Trash, and drag directly into open Files/Nautilus windows.

Live Image & Thumbnail Previews

Renders freedesktop thumbnails (thumbnail::path) and direct Gio.FileIcon image previews alongside .desktop application launchers and symlink badges.

Zero Subprocesses (shexli Clean)

Monitors ~/Desktop, trash:///, and Gio.VolumeMonitor mounts via pure asynchronous GIO APIs with 0 shexli findings.

Kelp & Reef Accent Borders

Selected and hovered desktop tiles display a crisp accent border ring with 1-click presets (Gruvbox Amber, Kelp Emerald, Ocean Cyan, Coral Red).

Quick Install

Install from the latest GitHub Release bundle across Fedora, Debian, Ubuntu, Arch, openSUSE, and NixOS:

gnome-extensions install --force seabed@ubermetroid.github.io.shell-extension.zip
gnome-extensions enable seabed@ubermetroid.github.io
